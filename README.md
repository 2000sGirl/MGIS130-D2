# MGIS130-D2
The live weather forecasting data is the information that goes into the app. This forecasting data is going to come from the OpenWeather web service that already collects this information.

Operationally, the app will have the ability to convert temperatures from Celcius to Farenheit, and vice versa.

Weather icons, such as a sunshine emoji or a half sun with a cloud emoji, will be displayed alongside the numerical temperature to illustrate what the weather is.
